# Resonance 发布文案

## 简介

A local multi-model AI workspace for collaborative tasks, workflows, and artifact review.

本地多 AI 协作工作台：连接不同模型，由总控协调任务，在一个对话窗口查看汇总、审批与成果。

Topics 建议：ai-agents、multi-agent、llm、workflow、electron、local-first。

## Release 标题

Resonance v1.1.3

新增 8 项可启停的内置技能，按任务选取并用于实际模型请求；PPT 支持多种版式、配色与可编辑导出。包含流式回复、对话版本和归档、可导入工作流、集中设置、开发检查点和隔离网站测试。当前为 Windows 预览版；自主调度、完整 MCP 传输、自动更新和签名尚未完成。

## 抖音文案

一个窗口，和多个 AI 一起做事。

把需求交给总控，展开查看各成员的回复；常用任务保存为工作流，结果集中审阅。Resonance，本地运行的多 AI 工作台。
