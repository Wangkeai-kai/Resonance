# Resonance v1.1.3

Windows 预览版：本地多模型协作、对话、工作流与成果审阅。

## 本次修复

- 本地 API 加入每次启动生成的访问凭证，覆盖聊天、SSE、图片、审批、任务和 MCP；桌面端自动连接。
- 主界面禁用内联脚本，网站成果使用独立沙盒预览，保留交互并隔离工作台权限。
- 审计日志按大小轮转、从尾部读取，保留独立历史任务标记，避免每次启动扫描完整历史。
- 源码只保留 `启动Resonance.cmd`，避免旧名称重复入口。

## 下载与启动

下载 `Resonance-v1.1.3-Windows-x64.zip`，解压整个目录，双击 `Resonance.exe`；不要只复制 exe，也不需要再运行源码启动脚本。压缩包附带当前用户安装脚本，可用于建立桌面快捷方式。

升级前正常关闭旧版并备份 `%APPDATA%\Gongming`。数据目录仍使用原名称；请勿删除工作区或密钥文件。源码包供开发使用，需要 Node.js 22+，启动后打开终端输出的完整访问链接。

## 验证与边界

256 项自动化测试通过，另有后端集成检查、真实浏览器界面回归和隔离数据目录桌面启动检查。界面与生成工作流测试使用本地模拟模型，不计入真实厂商模型效果或付费调用验证。

软件尚未代码签名，不包含自动更新，仍是 Windows 单机预览版。安全加固、日志保留规则和企业部署待办见仓库 `docs/SECURITY-HARDENING.md`。
