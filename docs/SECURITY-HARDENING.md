# v1.1.3 安全加固与验证边界

本版本以已发布的 v1.1.2 为基线，处理本地 API 鉴权、审计日志增长与主界面内联脚本三项问题。它仍是 Windows 单机预览版，不代表已完成企业级合规认证或多租户权限系统。

## 启动入口

- 桌面版：只打开 `Resonance.exe`。无需再运行源码脚本。
- 源码版：安装 Node.js 22+，运行 `npm start` 或唯一入口 `启动Resonance.cmd`，打开终端输出的完整链接。链接中的 `#session=` 为本次启动的访问凭证，不要分享截图或完整链接。
- 不再分发旧名称的 `启动共鸣.cmd`。重复启动相同工作区会被所有者锁拒绝，不会自动结束正在工作的实例。
- 服务重启后旧访问凭证失效。桌面自动获取新凭证；浏览器需使用新的完整链接。

## API 鉴权

后端启动生成 256 位随机凭证，全部 `/api/*` 请求都必须携带 `Authorization: Bearer`。覆盖状态、历史、图片、SSE、审批、MCP 和任务操作。Host、Origin 和 JSON 写操作检查继续保留。

桌面端通过父子进程 IPC 获取凭证，预加载层只允许主工作台窗口获取，不提供通用 IPC。凭证不写入 desktop.json、工作区快照或诊断日志。源码模式只将访问链接输出到启动终端；浏览器收到后从地址栏移除片段，在本标签的 sessionStorage 中保存以支持刷新。图片通过鉴权 fetch 加载为 Blob URL，离开页面后释放。

这是防止未获授权的本地 HTTP 客户端访问工作台的边界，不是对同一用户恶意程序、管理员、调试器或已被攻陷渲染进程的隔离承诺。现有模型密钥仍由桌面的系统凭据保护机制管理。

## CSP 与作品预览

主界面使用 `script-src 'self'` 和 `script-src-attr 'none'`，禁止内联脚本、HTML 事件处理器和 eval。样式暂保留内联支持，以兼容现有界面。

网站交互预览改为独立 HTTP 沙盒文档，不再通过继承主界面 CSP 的 srcdoc 执行脚本。创建预览要求 API 鉴权，返回的随机访问凭证仅能读取对应文档，有效期 5 分钟，最多缓存 16 份，每份不超过 2 MiB。预览响应强制 `sandbox allow-scripts`，不允许同源权限、外网连接、子框架或表单提交。即使独立打开预览 URL，也无法获得工作台 API 权限。

预览内部允许作品自身的内联脚本，这与主界面权限分离；不应把它误报成主界面允许内联脚本。预览文档包含用户作品，仍不应公开分享临时预览 URL。

## 审计保留策略

新日志每段不超过 8 MiB，保留当前段与最近 32 个历史段；达到上限会清理最旧历史段。轮转采用同目录重命名，记录落盘后才加入界面缓存。需要长期合规归档的组织必须另行备份工作区并制定保留政策，本版本不提供 WORM 或签名审计。

读取最新记录采用 64 KiB 反向块读取，分页可跨段、按任务过滤，过期游标返回 409。独立元数据保留“曾有历史任务”的证据，即使原始事件因保留策略被清理，仍阻止把丢失的任务主记录当作空工作区覆盖。

旧版日志首次升级执行一次完整校验，后续启动从尾部读取。历史超大文件会原样封存，随着分段保留策略逐步淘汰，因此已有超大日志在过渡期可能超过上述新日志容量。分段目前未压缩。损坏日志或元数据仍停止启动并保留原文件；只读修复界面属于后续工作，不会静默跳过损坏记录。
