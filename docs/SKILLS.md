# 常用技能

打开「设置 → 助理与技能」，即可查看内置方法。不用逐一安装，开始对话或任务后，工作台按任务内容和角色选择。

| 技能 | 使用场景 |
| --- | --- |
| PPT 内容与版式 | 演示大纲、逐页表达、对照与流程版式 |
| 网站设计与交互 | 页面层级、响应式、主要操作与失败状态 |
| 报告与资料整理 | 事实、分析、建议、引用与待确认信息 |
| 项目计划与交接 | 工作包、依赖、负责人和验收条件 |
| 需求分析与验收 | 原始要求、完成标准和证据核对 |
| 代码开发与审阅 | 相关源码、接口、正确性与兼容问题 |
| 测试与故障排查 | 复现步骤、失败原因、实际验证范围 |
| 日常工作整理 | 问答、会议记录、决定和行动项 |

内置技能默认启用，可以分别停用，重启后保留选择。查看内容后可复制为「我的技能」再修改，更新软件不会覆盖自己的版本。也可点击「添加技能」，输入名称和说明，或导入 SKILL.md / 文本文件。导入只保存说明，不安装附属脚本。

任务中的「使用的技能」列出各阶段实际请求携带的方法名称。每次最多选择 2 个相关内置技能与最近 2 个启用的自定义技能，正文合计最多 8,500 字符。自定义技能默认用于所有任务，请停用本次不相关的内容，避免相互冲突。这是字符预算，不是对服务商 token 用量的承诺。

技能不能增加工具权限、绕过审批或证明执行成功。最终效果仍取决于模型能力、用户提供的事实和实际验证。普通聊天只产生回复，制作交付物需启动任务。

PPT 支持分项说明、两项对照、步骤流程、单一重点四种版式。预览和导出使用同一布局；在审阅中编辑页面可切换适合当前内容项数量的版式。暂不支持复杂图表、插图与母版。
